EXPERIMENT ID REFERENCE
=======================

This file maps the 117 IDs defined in configs/experiments.py to their model
configurations. It describes configurations, not measured results.

How to read the columns
-----------------------
ID: integer passed to train.py --exp_id.
Experiment name: name used by the configuration and output directory.
Fusion: method used to combine the modalities (single for one source).
TCM: whether the Temporal Compression Module is enabled.
Window: full = no temporal cutoff; 3m = through day 91; 6m = through day 182.
  Days are measured from the dataset reference date (2018-09-01). The cutoff
  keeps dates on or before that day, including any earlier observations.
  If a source has none, the nearest available acquisition is retained.

Modality sets
-------------
S2: Sentinel-2 optical.
S1A / S1D: ascending / descending Sentinel-1 SAR.
N3: S2 + S1A + S1D (three separate model-facing sources).
N5: N3 + S1ABcoh + S1DBcoh (five separate sources).
hybrid: three model-facing sources: S2, S1A with its coherence channels,
  and S1D with its coherence channels. Coherence is resampled to the
  corresponding SAR acquisition dates before channel concatenation.

Fusion methods
--------------
single: one modality; no cross-modal fusion.
early: resample sources to the S2 time grid and concatenate channels before
  a shared temporal front end and backbone.
aligned: concatenate TCM-compressed, slot-aligned features and apply a 1x1
  convolution before the shared backbone.
late: concatenate per-modality decoder features, then predict from their
  fused representation; per-modality heads receive auxiliary supervision.
decision: average the per-modality prediction logits.
cross_s2: S2-centered temporal cross-attention over the other modalities.
cross_nn: each modality attends to the others over TCM slots.
sacf: slot-aligned cross-modal fusion via SACF.

TCM compresses each input time series to four temporal slots when enabled.
The rest of the network includes the U-TAE temporal encoder for both TCM
and non-TCM configurations.
